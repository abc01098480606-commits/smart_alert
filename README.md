# Smart Alert

Smart Alert 개발 전용 작업 저장소입니다.

## 목적
- 문서/기획서: OneDrive
- 코드/개발: Git 저장소
- 개발 환경: 이 계정 전용

## 구조
- apps/: 애플리케이션 코드
- src/: 공용 라이브러리 / 서비스
- docs/: 기획서/요구사항/설계 문서
- notes/: 작업 메모
- scripts/: 자동화 스크립트

## 작업 원칙
- 문서는 OneDrive로 관리
- 코드는 Git으로 관리
- 빌드/캐시/가상환경은 저장소 루트 외부 또는 제외
- 작업 브랜치별 진행
